## 1. Resumen Ejecutivo

Nos complace anunciar el lanzamiento de **Cloud Document Manager (CDM) v0.1.0**, el primer hito mayor (MVP) de la plataforma SaaS multi-tenant para el almacenamiento seguro, catalogación y procesamiento asíncrono de documentos en la nube.

Este release materializa una solución empresarial de portafolio de grado productivo, combinando **Arquitectura Hexagonal (Ports & Adapters)** en Python 3.12, un frontend reactivo **Angular 22 Zoneless con Signals**, persistencia transaccional en **PostgreSQL 16**, infraestructura declarativa en **Terraform 1.7+** y un ecosistema serverless en **AWS (S3, SQS, Lambda, Cognito, API Gateway, CloudWatch)** con **cero costes ocultos**.

## 2. Capacidades Entregadas por Épica

### Épica 01: Fundación, Arquitectura y Repositorio (`CDM-2`)
- Estructuración del monorepo (`apps/api`, `apps/web`, `infrastructure/terraform`, `docs/`, `scripts/`).
- Documento rector [`AGENTS.md`](../../AGENTS.md) con políticas de ingeniería, seguridad, costes y gobierno.
- Decisiones de arquitectura formalizadas en ADRs (ADR-0001 a ADR-0008).
- Entorno de desarrollo local con Docker Compose para PostgreSQL 16 y `uv` para Python.
- Pipeline de integración continua (CI) en GitHub Actions validando linting, tipado estricto y tests.

### Épica 02: Infraestructura Base en AWS con Terraform (`CDM-3`)
- Módulos IaC reutilizables y modulares: `cognito`, `s3-storage`, `sqs-worker-queue`, `lambda-api`, `lambda-worker` y `observability-cloudwatch`.
- Entorno dev con configuración least-privilege y restricciones financieras (*AGENTS.md* §13: sin NAT Gateways ni balanceadores continuos).
- Políticas de retención en CloudWatch Logs (7 días en dev) para control de gasto.

### Épica 03: Dominio, Persistencia y Multi-Tenancy (`CDM-4`)
- Capa de Dominio pura sin dependencias de frameworks ni ORMs: entidades `User`, `Workspace`, `WorkspaceMembership`, `Document`, `UploadSession`.
- Modelo de roles jerárquicos acordado (ADR-0001): `VIEWER < MEMBER < EDITOR < ADMIN < OWNER`.
- Persistencia mediante SQLAlchemy 2.0 y gestión de esquema con migraciones Alembic.
- Aislamiento multi-tenant estricto: toda consulta filtra por `workspace_id` autorizado verificado en BD.

### Épica 04: Autenticación, Usuarios y API Gateway (`CDM-5`)
- Integración con Amazon Cognito User Pool para registro, autenticación y refresh tokens.
- Verificador de tokens JWT con validación de firma JWKS en memoria, expiración y claims.
- Adaptador ASGI Mangum sobre AWS Lambda API con API Gateway HTTP API v2.
- Endpoints de perfil (`/api/v1/me`), creación y selección de workspaces y administración de miembros.

### Épica 05: Almacenamiento Seguro y Carga Directa a S3 (`CDM-6`)
- Carga directa desde el navegador a S3 mediante URLs prefirmadas PUT de vida corta (15 min).
- Allowlist estricta de formatos (PDF, PNG, JPEG, WEBP, TXT, CSV) y validación de nombres de archivo anti-path traversal.
- Confirmación de carga transaccional (`POST /complete`) con reconciliación física `HeadObject`.
- Tarea y caso de uso de limpieza automática de sesiones expiradas y objetos huérfanos.

### Épica 06: Procesamiento Asíncrono con SQS y Lambda (`CDM-7`)
- Desacoplamiento de eventos `s3:ObjectCreated:*` hacia cola SQS estándar.
- AWS Lambda Worker procesando eventos por lote con reporte de fallos parciales (`batchItemFailures`).
- Cola de mensajes muertos (Dead Letter Queue - DLQ) con alarma de mensajes visibles >= 1.
- Inspección técnica de contenido (detección de magic bytes y cálculo de checksum SHA-256 en memoria).

### Épica 07: Catálogo, UI Angular y Accesibilidad WCAG AA (`CDM-8`)
- SPA reactiva construida en Angular 22 utilizando `provideZonelessChangeDetection()` y Signals.
- Diseño accesible conforme a las pautas WCAG AA (skip-link, contraste 4.5:1+, roles ARIA y foco visible).
- Catálogo documental con filtros por estado (`READY`, `PROCESSING`, `FAILED`), paginación y búsqueda.
- Flujo de carga drag & drop con barra de progreso reactiva en tiempo real.
- Detalle modal con metadatos técnicos, descarga autorizada temporal y confirmación destructiva de borrado lógico.

### Épica 08: Calidad, Seguridad, Observabilidad y Release (`CDM-9`)
- **Suite de pruebas backend:** 268 pruebas unitarias, de integración, contrato y seguridad multi-tenant (100% pasando).
- **Suite de pruebas frontend:** 100 pruebas unitarias en Vitest de componentes, servicios e interceptores (100% pasando).
- **Pruebas End-to-End (E2E):** 18 pruebas en Playwright cubriendo todos los journeys del usuario (Auth, Workspaces, Upload, Catalog/Actions).
- **Revisión de Seguridad OWASP:** Análisis de 8 controles OWASP File Upload, mitigación API Security Top 10, rate limiting en memoria y sanitización automática de logs en tiempo real (`SensitiveDataSanitizingFilter`).
- **Observabilidad CloudWatch:** Formato estructurado JSON con trazabilidad contextual (`X-Request-ID` y SQS `messageId`), métricas y 4 alarmas CloudWatch con tópico SNS.
- **Runbooks Operativos:** Documentación de arquitectura global (`system-architecture.md`), contingencias operativas (`operations-runbook.md`), backup/restore (`backup-restore.md`) y teardown AWS (`aws-teardown.md`).
- **Demostración Automatizada:** Script reproducible `scripts/demo_e2e_walkthrough.py` validando los 12 pasos del MVP.

## 4. Matriz de Endpoints de la API v1

| Método | Endpoint | Rol Requerido | Descripción |
|---|---|---|---|
| `GET` | `/health` | Público | Verificación de salud y versión de la API |
| `GET` | `/api/v1/me` | Autenticado | Perfil e identidad del usuario activo |
| `POST`| `/api/v1/workspaces` | Autenticado | Crear un nuevo workspace (asigna rol OWNER) |
| `GET` | `/api/v1/workspaces` | Autenticado | Listar workspaces del usuario con sus roles |
| `GET` | `/api/v1/workspaces/{id}/members` | MEMBER+ | Listar miembros y roles del workspace |
| `POST`| `/api/v1/workspaces/{id}/members` | ADMIN / OWNER | Invitar o agregar miembro con un rol |
| `POST`| `/api/v1/workspaces/{id}/upload-sessions` | MEMBER+ | Iniciar carga y generar URL prefirmada S3 |
| `POST`| `/api/v1/workspaces/{id}/upload-sessions/{id}/cancel` | MEMBER+ | Cancelar sesión de carga en curso |
| `POST`| `/api/v1/workspaces/{id}/documents/{id}/complete` | MEMBER+ | Confirmar carga binaria y verificar en S3 |
| `GET` | `/api/v1/workspaces/{id}/documents` | VIEWER+ | Listar catálogo documental con filtros y paginación |
| `GET` | `/api/v1/workspaces/{id}/documents/{id}` | VIEWER+ | Detalle de documento y metadatos técnicos |
| `POST`| `/api/v1/workspaces/{id}/documents/{id}/download-url` | VIEWER+ | Generar URL prefirmada temporal para descarga |
| `DELETE`| `/api/v1/workspaces/{id}/documents/{id}` | EDITOR+ | Eliminación lógica del documento |
| `POST`| `/api/v1/workspaces/{id}/documents/{id}/retry` | EDITOR+ | Reintentar procesamiento de documento fallido |

## 5. Instrucciones de Puesta en Marcha

Consultar la guía paso a paso en el [`README.md`](../../README.md):
```bash
# Entorno local
cp .env.example .env
docker compose up -d
cd apps/api && uv sync && uv run alembic upgrade head && uv run uvicorn cdm.bootstrap.app:app --reload
cd apps/web && pnpm install && pnpm start

# Demostración E2E
cd apps/api && uv run python ../../scripts/demo_e2e_walkthrough.py
```
